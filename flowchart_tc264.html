CPU0 — Image Processing Core CPU1 — Control Core Shared Memory (IPC)
Architecture Notes:
• CPU0 is dedicated to image processing only: camera init, DMA capture, Otsu binarization, line search, element detection (roundabout/zebra/ramp/roadblock), line repair. Outputs Err and ImageStatus flags to shared memory.
• CPU1 handles all real-time control (encoder, motor PI, servo PD, differential compensation) plus LCD display, key scanning (placeholder only - functions TBD), IMU/gyroscope (Kalman filter, yaw/pitch), and serial debug.
• Keys are on CPU1 but not yet bound to servo angle or speed control. Key functionality will be implemented later.
• Cross-core IPC: CPU0 writes Err and image status flags; CPU1 reads them for control decisions.
